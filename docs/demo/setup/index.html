Workflow

  1. Download the templates below.
  2. Fill them in with your plant's data (Excel, Numbers, Google Sheets — anything that saves as CSV).
  3. Upload them back in the Upload section.
  4. All templates are processed in dependency order, regardless of the order you select them.
  5. Read the Upload Report to confirm what landed and fix any rows that failed.

Templates

Each template contains the column headers and two example rows showing the format. Column order in your upload does not matter, but the column names must match exactly.
File What it contains
lines.csv Lines in the plant Download →
skus.csv SKUs and part numbers. case_pack is units per case. Download →
component_types.csv BOM component types. is_serial=1 means the component always changes (e.g. formulation). Download →
sku_bom.csv Bill of materials per SKU. One row per component per SKU. Download →
line_sku_rates.csv Ideal production rate per line per SKU, in units per HOUR. Download →
co_procedures.csv Changeover procedures: line, from-SKU, to-SKU, standard minutes. Download →
co_steps.csv Steps per changeover procedure. Identified by line + from + to. Download →
jobs.csv Weekly schedule. Uploaded again each week; existing job numbers are updated. Download →
users.csv Line leads and managers. telegram_id maps to a Telegram account. Download →
settings.csv Configuration: unit label, shift times, lunch duration. Download →
